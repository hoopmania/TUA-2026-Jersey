# TU Basketball Alumni — แบบฟอร์มสั่งจองชุด

ฟอร์มสั่งจองชุด Thammasat Basketball Alumni (`index.html`, ไฟล์เดียวจบ ไม่มี build step)
พร้อม backend เก็บออเดอร์ลง Google Sheet ผ่าน Apps Script (`apps-script/Code.gs`)

## โครงสร้าง

```
index.html             หน้าฟอร์มสั่งจอง (host บน GitHub Pages)
status.html            หน้าลูกค้าเช็คสถานะคำสั่งซื้อเอง (ค้นด้วยชื่อ+เบอร์)
checkin.html           หน้าแอดมินเช็คชื่อ/ติ๊กว่ามารับชุดแล้ว (ต้องมี ?token=... ต่อท้ายลิงก์)
report.html            หน้าแอดมินดูรายงานยอดขายรายวัน (ต้องมี ?token=... ต่อท้ายลิงก์ เหมือน checkin.html)
apps-script/Code.gs     โค้ด backend (วางใน Google Apps Script ของชีต)
```

## ขั้นตอนที่ 1 — ตั้งค่า Apps Script (เก็บออเดอร์ลงชีต)

1. เปิด Google Sheet **"2026 Pre-Order Uniform TU Bas"**
2. เมนู **Extensions > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจาก `apps-script/Code.gs` ในโปรเจกต์นี้แทน
4. กด **Deploy > New deployment**
   - Select type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
5. กด **Deploy** → อนุญาตสิทธิ์ (จะมีหน้าเตือนว่าแอปยังไม่ยืนยันตัวตน กด Advanced > ไปต่อ ได้เลย เพราะเป็นสคริปต์ของคุณเอง)
6. คัดลอก **Web app URL** ที่ได้ (หน้าตาประมาณ `https://script.google.com/macros/s/xxxxx/exec`)
7. เปิด `index.html` หาบรรทัด:
   ```js
   var APPS_SCRIPT_URL = 'PASTE_YOUR_WEB_APP_URL_HERE';
   ```
   แล้ววาง URL ที่คัดลอกมาแทน `PASTE_YOUR_WEB_APP_URL_HERE`

**หมายเหตุ**: ทุกครั้งที่แก้โค้ดใน `Code.gs` ต้องกด **Deploy > Manage deployments > แก้ไข (ไอคอนดินสอ) > Version: New version > Deploy** ใหม่ ไม่งั้นระบบจะยังใช้โค้ดเวอร์ชันเก่าอยู่

ทดสอบ: เปิด `index.html` ในเบราว์เซอร์ (เปิดจากไฟล์ในเครื่องก็ทดสอบได้เลย) ลองกรอกออเดอร์ปลอมทั้งหมดจนถึงหน้าชำระเงิน แนบรูปอะไรก็ได้เป็นสลิป แล้วกด "ยืนยันคำสั่งซื้อ" — เช็คว่ามีแถวใหม่ขึ้นในชีต (tab "Orders") และมีไฟล์ในโฟลเดอร์ Drive ชื่อ "TU Basketball Preorder Slips"

## ขั้นตอนที่ 2 — ขึ้น GitHub Pages (เพื่อได้ลิงก์สำหรับโปสเตอร์/QR)

Repo: **https://github.com/hoopmania/TUA-2026-Jersey** (สร้างไว้แล้ว)

โฟลเดอร์นี้ init เป็น git repo, ตั้ง remote ไปที่ repo ข้างบน, และ commit ไฟล์ทั้งหมดไว้ให้แล้ว เหลือแค่ push:

```bash
git push -u origin main
```

ถ้าเป็นครั้งแรกที่ push จากเครื่องนี้ Git Credential Manager จะเปิดเบราว์เซอร์ให้ล็อกอิน GitHub — ล็อกอินแล้วค่อยลองรันคำสั่งข้างบนอีกครั้งถ้าจำเป็น

จากนั้นเปิด **Settings > Pages** ของ repo → Source เลือก **Deploy from a branch** → Branch: **main**, folder: **/ (root)** → Save

รอสัก 1-2 นาที ลิงก์ฟอร์มจะอยู่ที่ `https://hoopmania.github.io/TUA-2026-Jersey/` — เอาลิงก์นี้ไปทำ QR code และใส่ในโปสเตอร์ได้เลย

## ขั้นตอนที่ 3 — เปิดใช้หน้าเช็คสถานะ/แอดมิน

**หน้าลูกค้าเช็คสถานะเอง** (`status.html`) ใช้งานได้ทันทีไม่ต้องตั้งค่าเพิ่ม ลิงก์คือ
`https://hoopmania.github.io/TUA-2026-Jersey/status.html`

**หน้าแอดมินเช็คชื่อรับของ** (`checkin.html`) ต้องตั้งรหัสก่อนครั้งเดียว:
1. เข้า Apps Script editor ของชีต (ที่วาง `Code.gs` ไว้) เลือกฟังก์ชัน **`setAdminToken`** จาก dropdown ด้านบน แล้วกด **Run**
2. เปิด **View > Logs** จะเห็นรหัสที่สุ่มให้ พร้อมลิงก์เต็มแบบ `checkin.html?token=xxxxxxxx`
3. คัดลอกลิงก์เต็มนั้นไปเก็บไว้ที่ตัวเอง (เช่น บันทึกในโน้ตส่วนตัว หรือ bookmark) — **ห้ามโพสต์ลิงก์นี้ที่สาธารณะ** เพราะใครมีลิงก์นี้แก้ไขสถานะออเดอร์ได้เลย
4. อยากเปลี่ยนรหัสใหม่เมื่อไหร่ก็รัน `setAdminToken` ซ้ำได้ (รหัสเก่าจะใช้ไม่ได้ทันที)

**อัปเดตสถานะทั้งชุด** — เปิด Google Sheet แล้วรีเฟรชหน้าหนึ่งครั้ง (ให้เมนูขึ้น) จะเห็นเมนู **"สถานะออเดอร์"** บนแถบเมนูของชีต ไล่กดตามลำดับขั้นตอนจริงของงานได้เลย (สรุปยอด → อยู่ในขั้นตอนการผลิต → ผลิตเสร็จแล้ว รอการจัดส่ง → จัดส่งแล้ว → พร้อมให้มารับที่โรงยิม) แต่ละคลิกจะอัปเดตทุกแถวให้พร้อมกันทันที (ขั้นสุดท้ายอัปเดตเฉพาะกลุ่มที่เลือกรับเองเท่านั้น อัตโนมัติ)

**ดูสถิติการสั่งซื้อ** — จากเมนู "สถานะออเดอร์" กด **"ดูสถิติการสั่งซื้อ (สรุปแยกรุ่น/ชนิดเสื้อ)"** จะสร้าง/อัปเดตแท็บใหม่ชื่อ "สถิติการสั่งซื้อ" ในชีตเดียวกัน (ใช้สูตร QUERY/COUNTIF อ้างอิงกลับไปที่แท็บ Orders โดยตรง อัปเดตอัตโนมัติทุกครั้งที่มีออเดอร์ใหม่ ไม่ต้องกดเมนูซ้ำ) แสดง: จำนวนรายการแยกตามรุ่น, จำนวนคนสั่งเสื้อกล้ามเทียบเสื้อแขนสั้น, จำนวนคนสั่ง/ไม่สั่งกางเกง, และจำนวนคนที่สั่งเสื้อ+กางเกงเป็นชุด — อยากดูมุมอื่นเพิ่มเติมเองก็เลือกช่วงข้อมูลในแท็บ Orders แล้วใช้ **Insert > Pivot table** ของ Google Sheets ได้เลย

**หน้ารายงานยอดขาย** (`report.html`) ใช้ token เดียวกับ `checkin.html` (ตั้งครั้งเดียวตามขั้นตอนด้านบน) เปิดผ่านลิงก์
`https://hoopmania.github.io/TUA-2026-Jersey/report.html?token=xxxxxxxx` จะเห็นยอดรวมทั้งหมด, ตารางสรุปยอดขายแยกรายวัน และเลือกดูรายละเอียดออเดอร์ของวันใดวันหนึ่งได้ (นับยอดจากคอลัมน์ "ยอดแจ้งการโอน (บาท)" ของแถวแรกในแต่ละออเดอร์ กันนับซ้ำกรณีออเดอร์เดียวมีหลายแถว)

## ข้อควรระวัง

- ไฟล์สลิปที่แนบจะถูกแปลงเป็น base64 ส่งผ่าน POST ไปให้ Apps Script — ถ้าไฟล์ใหญ่มาก (เช่นรูปถ่าย 10MB+) อาจช้าหรือเกินขีดจำกัดของ Apps Script (~50MB ต่อ request) แนะนำเตือนผู้สั่งซื้อให้แนบรูปสลิป ไม่ใช่รูปถ่ายความละเอียดสูงเกินจำเป็น
- Web App ที่ตั้ง Access เป็น "Anyone" หมายความว่าใครก็ยิง request เข้ามาที่ URL นี้ได้ (ไม่ใช่แค่จากฟอร์มนี้) — สำหรับงานสั่งจองขนาดนี้ถือว่าเพียงพอ แต่ไม่ควรเก็บข้อมูลอ่อนไหวอื่นเพิ่มในนี้
- ราคา/ไซส์ ในฟอร์มยังเป็นค่าที่ hardcode ไว้ใน `index.html` (ตัวแปร `PRICE` และ `SIZE_CHART`) ถ้าราคาชุดเปลี่ยนต้องแก้ในไฟล์นี้แล้ว commit ใหม่
- **ห้ามใส่รหัสแอดมินจริงลงในไฟล์ที่ commit ขึ้น GitHub เด็ดขาด** (repo นี้เป็น public) — รหัสเก็บอยู่ใน Apps Script "Script Properties" เท่านั้น (ตั้งผ่าน `setAdminToken()`) ไม่ได้อยู่ในซอร์สโค้ดที่ push ขึ้นมา
